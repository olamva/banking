# docs

The privacy policy and terms of use, required to register the Enable Banking
application. They are not project documentation — see the root `README.md` for
that.

## These are published, and the published copy is a separate one

Enable Banking needs public URLs, and this repo is private, so both documents
are also published as a gist:

<https://gist.github.com/olamva/b3f7205de8db1ad59b82651a7827f983>

The gist is an independent copy. It does not read from this repo and cannot —
moving or renaming these files changes nothing about it. The two are currently
byte-identical.

**So editing a file here does not update what Enable Banking sees.** If either
document changes, edit the gist too, in the same sitting. That is the whole
reason this note exists: there is no mechanism keeping the copies in step, only
the habit.

One more trap: the raw URLs GitHub hands out for a gist are pinned to a
revision, e.g. `.../raw/a4ce4bc.../PRIVACY.md`. A pinned URL keeps serving the
old text forever after an edit. The unpinned form, `.../raw/PRIVACY.md`,
follows the latest revision — check which one was registered before assuming an
update took effect.
